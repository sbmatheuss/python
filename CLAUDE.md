# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

This repository contains exercises and materials from the **Curso de Python3 do CursoemVideo** (Python 3 course by CursoemVideo, a Portuguese-language online platform). It is a personal learning repository.

## Running Python Files

Since there is no build system or package structure, files are run directly:

```bash
python <filename>.py
```

## No External Dependencies

This project has no `requirements.txt` or virtual environment setup — course exercises use only the Python standard library.
